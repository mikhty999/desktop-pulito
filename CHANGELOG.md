# Changelog

## 1.0.0

First public release.

- Hide/show desktop icons from the tray, with `Ctrl+Alt+D`, or by double-clicking the desktop
- Liquid transition (frosted-glass blur) and classic fade, three speeds
- Desktop search (`Ctrl+Alt+F`): draggable glass panel, remembers its position, recent items first
- Auto-hide with pause, Zen mode (taskbar too)
- 8 gradient themes, Windows 11 acrylic glass, light/dark/system theme, colored or mono tray icon
- English and Italian
- Start with Windows, reset, one-click uninstall
